======= Prerequisite & Steps for PySpark Setup =======

Step 1: Install JDK 17 or 21.
Windows steps


https://www.oracle.com/de/java/technologies/downloads/#jdk21-windows

Set JAVA_HOME to the new JDK folder, for example C:\Program Files\Java\jdk-21.0.11.

Put %JAVA_HOME%\bin first in PATH.

Open a new terminal and verify with java -version and javac -version.

Step 2: Install the necessary Python libraries: findspark and pyspark.

*** PySpark is the Python API for Apache Spark, an open-source engine for big data processing.

Thus, Apache Spark is an open-source (is built on Java), distributed processing system used for big data workloads. 
It utilizes in-memory caching, and optimized query execution for fast (100 x faster) analytic queries against data of any size.
